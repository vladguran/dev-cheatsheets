Quick Reference

Task Command
Show every HEAD move git reflog
Undo last reset/rebase/merge git reset --hard ORIG_HEAD
Restore a file from any commit git restore --source=<sha> -- path
Unstage, keep edits git restore --staged path
Fold staged changes into an old commit git commit --fixup=<sha> then git rebase -i --autosquash <base>
Move a branch to a new base git rebase --onto <newbase> <oldbase> <branch>
Compare two versions of a series git range-diff <base> <old-tip> <new-tip>
Find the regression commit git bisect start <bad> <good> then git bisect run <cmd>
Work on a second branch in parallel git worktree add ../hotfix -b hotfix origin/main
Safe force-push git push --force-with-lease --force-if-includes
Undo a pushed merge git revert -m 1 <merge-sha>
Copy a commit, recording its origin git cherry-pick -x <sha>
Find when a string appeared or vanished git log -S'needle' --oneline
Show the history of a function git log -L :funcName:path/file.c
Find lost commits and blobs git fsck --lost-found
