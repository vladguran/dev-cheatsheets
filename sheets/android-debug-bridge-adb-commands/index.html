Every ADB command you actually use for phones and Android/Google TV over USB or Wi-Fi. Targets Android SDK Platform-Tools 35+ (adb version → 1.0.41) with devices on Android 11–15.

Quick Reference

Task Command
List devices with model info adb devices -l
Target a specific device adb -s <serial> <cmd> (or export ANDROID_SERIAL=<serial>)
Pair over Wi-Fi (Android 11+) adb pair <ip>:<pair-port>
Connect over Wi-Fi adb connect <ip>:<port>
Install or update an APK adb install -r -g app.apk
Install split APKs adb install-multiple base.apk split_*.apk
Uninstall an app adb uninstall <pkg>
List third-party packages adb shell pm list packages -3
Launch an app by package adb shell monkey -p <pkg> -c android.intent.category.LAUNCHER 1
Force-stop an app adb shell am force-stop <pkg>
Clear app data adb shell pm clear <pkg>
Stream errors only adb logcat *:E
Take a screenshot to the host adb exec-out screencap -p > shot.png
Send a remote or hardware key adb shell input keyevent KEYCODE_HOME
Copy files adb push local /sdcard/ · adb pull /sdcard/file .
